PCT Catalyst — PDF Visual Assets
=================================

Drop image files here to have them surface in the app.

Expected filenames (PNG or JPG):
  framework.png          — The PCT 4-quadrant wheel / overview diagram
  heart-head-hands.png   — Heart / Head / Hands framework visual
  mbd.png                — MBD Activator (More Of / Better / Differently) diagram
  pulse-intro.png        — PCT Pulse introduction visual
  shifts-intro.png       — Shifts concept visual
  quadrant-aspiration.png
  quadrant-alignment.png
  quadrant-autonomy.png
  quadrant-accountability.png

The app checks for each file at load time and renders a labelled
placeholder if the image is not present — so the app works at all
times, with or without these files.
